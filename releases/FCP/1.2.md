## v1.2.1.1/ v1.2.1.0
<!-- truncate -->

#### **New Features / Changes for Members**
- Updated validation for gaining a callsign to avoid confusion and allow for better callsign selection.

#### **Other Changes**

- Removed last names from Public Profiles as they were added accidentally
- Moved bigger parts of the Javascript to seperate chucks to allow for better loading and less usage taken within the browser 

#### **Developer Experience Changes**

- Added Docker compose for easy comparison between local and sever configs. 
  - KNOWN ISSUE: when running the migrations within the web container for the first time, the schema migration will not run properly. The following can be used as a work around:
    - Copy the ``/database/migrations/schema/`` 1st file contents.
    - Open a query console 
    - Paste the file contents in the query console
    - Run the query.
  - This *should* allow for the rest of the migrations to run properly without any further issues.

#### **Known Bugs / Issues**

- Some notifications have a white background when in dark mode


## v1.2.0.1

#### **New Features / Changes for Members**
- Fixed a bug where some members "Aircraft Hangar" may not load properly
- Added Company Gates
  - Members have the ability to view current company gates and use the search function to search for company gates quicker.
- Added page the shows Sector Map on the whole page allowing for better visibility.
#### **New Features / Changes for Staff**
- Added the ability to edit webhook links on the fly in case of discord changes or channel changes
- Added Company Gates
  - Added the ability to add airports and pictures of our company gates to FCP via Admin Panel.
- Added a filter to user admin panel to search members by TPC callsign
- Added ability to add/edit User Skills and add/edit aircraft skill on admin panel.

#### **Bug Fixes**

- Fixed a big where the Long Haul and Explorer flights have broken links if they are not posted on TPC Blog.
- Fixed a bug where some audit log entries did not have a "submitted by" record.
- Fixed an issue where the buttons on the bottom of the "Members" page would not load the next page.

#### **Other Changes**

- Added some caching rules to improve speeds of site
- Removed old code thats no longer in use anymore
- Changed flow for when a members record is deleted from the database.
- Switched all images to CDN to allow for faster loading and better experience when using site.

#### API Changes

- Set ``/users/find/{discord_id}/audit-logs/new`` as deprecated.
- Created ``/users/audit-logs/new`` for replacement of deprecated endpoint.

#### **Known Bugs / Issues**

- Some notifications have a white background when in dark mode
